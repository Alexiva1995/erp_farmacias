🔧 Detalles Técnicos de Implementación

🔐 Solución de Problema de Autenticación

Problema identificado: El módulo "Por Pagar" no mostraba datos debido a que las llamadas a la API no incluían el token de autenticación requerido por el sistema.

✅ Solución Implementada:

  • Identificación del problema: El proyecto usa autenticación con tokens Bearer, pero el módulo no los incluía en las peticiones
  • Problema de rutas: Las rutas de /api/suppliers estaban fuera del middleware de autenticación, mientras que las rutas de /api/finances/pending-payments estaban dentro
  • Corrección de imports: Se corrigió el import de useCookie para usar el composable interno del proyecto
  • Headers de autenticación: Se agregaron headers de autenticación a todas las llamadas API:
    • Authorization: Bearer {token}
    • Accept: application/json
    • X-Requested-With: XMLHttpRequest
  • Nueva ruta autenticada: Se creó una ruta específica /api/finances/suppliers dentro del middleware de autenticación
  • Archivos modificados:
    • routes/api.php - Agregada ruta autenticada para suppliers
    • resources/js/pages/finances/pending-payments.vue - Cambiada URL a /finances/suppliers
    • resources/js/components/dialogs/ProcessPaymentModal.vue - Headers de autenticación

  "amount_usd": 150.00,
  "exchange_rate": 36.50,
  "total_invoice_amount": 1000.00,
  "notes": "Pago parcial realizado"
}
  • photo_url: URL del comprobante de pago
  • amount: Monto pagado en la moneda original
  • status: Estado del pago (paid/unpaid)

Tabla `invoices`:

  • status_payment: Estado del pago (paid/partial/unpaid)

Tabla `expenses`:

  • name: "Pago Factura # [número] Proveedor [nombre]"
  • amount: Monto pagado en moneda original
  • amount_usd: Monto convertido a USD
  • currency: Moneda del pago
  • user_id: Usuario que procesó el pago

📖 Guía de Uso del Módulo "Por Pagar"

🎯 Acceso al Módulo

Para acceder al módulo "Por Pagar":

  1. Iniciar sesión en el sistema ERP
  2. En el sidebar izquierdo, expandir la sección "Finanzas"
  3. Hacer clic en "Por Pagar"

📊 Vista Principal

La vista principal muestra:

  • Dashboard de estadísticas: Resumen de grupos pendientes, facturas vencidas, total de facturas y monto total
  • Filtros avanzados: Búsqueda por proveedor, fechas y estado de vencimiento
  • Tabla de pagos pendientes: Facturas agrupadas por proveedor y fecha de pago

🔍 Filtros Disponibles

El módulo incluye los siguientes filtros:

  • Búsqueda por proveedor: Campo de texto para buscar por nombre del proveedor
  • Selector de proveedor: Lista desplegable con todos los proveedores
  • Fecha desde/hasta: Rango de fechas de pago
  • Solo vencidos: Checkbox para mostrar únicamente facturas vencidas
  • Limpiar filtros: Botón para resetear todos los filtros

👁️ Visualizar Facturas

Para ver las facturas de un grupo de pago:

  1. En la tabla de pagos pendientes, localizar el grupo deseado
  2. Hacer clic en el botón "Ver" (ícono de ojo)
  3. Se abrirá un modal mostrando:
    • Información del proveedor
    • Fecha de pago
    • Lista detallada de facturas
    • Monto total del grupo
  4. Hacer clic en "Cerrar" para cerrar el modal

💳 Procesar Pagos

Para procesar un pago:

  1. En la tabla de pagos pendientes, hacer clic en el botón "Pagar" (ícono de tarjeta de crédito)
  2. Se abrirá el modal de procesamiento de pago
  3. Completar el formulario:
    • Moneda de pago: Seleccionar entre Bs, USD o COP
    • Monto a pagar: Ingresar el monto (puede ser parcial)
    • Fecha de pago: Seleccionar la fecha del pago
    • Comprobante: Subir imagen del comprobante (opcional)
    • Notas: Agregar observaciones (opcional)
  4. El sistema mostrará automáticamente:
    • Conversión a USD si la moneda no es USD
    • Indicador de pago parcial si el monto es menor al total
    • Tasa de cambio utilizada
  5. Hacer clic en "Procesar Pago" para confirmar

💰 Tipos de Pago

El sistema soporta dos tipos de pago:

  • Pago completo: Cuando el monto pagado es igual o mayor al total de las facturas
  • Pago parcial: Cuando el monto pagado es menor al total de las facturas

El sistema indicará visualmente el tipo de pago y el monto restante si es parcial.

🔄 Conversión de Monedas

El sistema maneja automáticamente la conversión de monedas:

  • Monedas soportadas: Bolívares (Bs), Dólares (USD), Pesos Colombianos (COP)
  • Conversión automática: Todos los pagos se convierten a USD usando las tasas del sistema
  • Tasas actualizadas: Se utilizan las tasas de cambio más recientes
  • Visualización: Se muestra el monto original y el equivalente en USD

📁 Gestión de Comprobantes

Para subir comprobantes de pago:

  • Formatos soportados: JPG, PNG, GIF (máximo 2MB)
  • Proceso: Seleccionar archivo en el modal de pago
  • Almacenamiento: Se guarda automáticamente en el servidor
  • Asociación: Se vincula automáticamente con el pago procesado

📈 Estados de Pago

El sistema maneja los siguientes estados:

  • Pendiente: Factura sin pagar
  • Parcial: Pago parcial realizado
  • Pagado: Pago completo realizado
  • Vencido: Factura con fecha de pago pasada

🔧 Funcionalidades Automáticas

Al procesar un pago, el sistema automáticamente:

  • Actualiza el estado de las facturas
  • Crea un registro en la tabla de pagos
  • Genera un gasto en el módulo de expenses
  • Crea la categoría "Pagos de Facturas" si no existe
  • Establece las relaciones entre facturas y pagos
  • Actualiza las estadísticas del dashboard

⚠️ Consideraciones Importantes

  • Transacciones: Todos los pagos se procesan en transacciones de base de datos
  • Validaciones: El sistema valida montos, fechas y archivos antes de procesar
  • Rollback: Si hay un error, se revierten todos los cambios
  • Auditoría: Se registra el usuario que procesó cada pago
  • Integridad: No se pueden procesar pagos de facturas ya pagadas

🔧 Resolución de Problemas Técnicos

⚠️ Problemas Identificados y Resueltos

Durante el desarrollo se identificaron y resolvieron 6 problemas técnicos importantes:

🔍 Problema 1: Error 404 en Procesamiento de Pagos

  • Problema: El método processPayment aplicaba métodos de query builder a una colección ya ejecutada
  • Solución: Cambiado de whereIn() y where() a filter() de colección
  • Archivos modificados: app/Http/Controllers/Api/PendingPaymentsController.php

🔍 Problema 2: Error de Truncación de Base de Datos

  • Problema: Campo reference VARCHAR(100) muy pequeño para JSON generado
  • Solución: Implementado JSON compacto con claves cortas y truncación de notas
  • Archivos modificados: app/Http/Controllers/Api/PendingPaymentsController.php

🔍 Problema 3: Error ENUM en Estado de Facturas

  • Problema: Intentando establecer status = 'paid' en columna ENUM que no acepta ese valor
  • Solución: Mapeo de estados: 'paid' → 'ordered', 'partial' → 'to_order'
  • Archivos modificados: app/Http/Controllers/Api/PendingPaymentsController.php

🔍 Problema 4: Moneda Incorrecta en Historial

  • Problema: Historial mostraba moneda de factura en lugar de moneda de pago
  • Solución: Corregido para usar payment_method y extraer amount_usd del JSON
  • Archivos modificados: app/Http/Controllers/Api/PendingPaymentsController.php

🔍 Problema 5: Inconsistencia de Códigos de Moneda

  • Problema: "BS" y "Bs" para bolívares causaban confusión y diferentes estilos CSS
  • Solución: Estandarización completa a códigos ISO 4217 (VES, USD, COP)
  • Archivos modificados: app/Http/Controllers/Api/PendingPaymentsController.php, resources/js/pages/finances/payment-history.vue, resources/js/components/dialogs/ProcessPaymentModal.vue

🔍 Problema 6: Validación de Respuestas API

  • Problema: Frontend esperaba {success: true} pero backend devolvía {status: 'success'}
  • Solución: Actualizada validación para aceptar ambos formatos
  • Archivos modificados: resources/js/pages/finances/pending-payments.vue, resources/js/components/dialogs/ProcessPaymentModal.vue

  • Búsqueda por Proveedor: Campo de texto para buscar por nombre del proveedor
  • Selector de Proveedor: Lista desplegable con todos los proveedores
  • Fecha Desde/Hasta: Rango de fechas de pago
  • Solo Vencidos: Checkbox para mostrar únicamente facturas vencidas
  • Limpiar Filtros: Botón para resetear todos los filtros

👁️ Visualizar Detalles de Facturas

Proceso de Visualización

  1. Localizar Grupo: En la tabla, encontrar el grupo de pago deseado
  2. Hacer Clic en "Ver": Presionar el botón con ícono de ojo
  3. Modal de Detalles: Se abrirá mostrando:
    • Información del proveedor
    • Fecha de pago
    • Lista detallada de facturas
    • Monto total del grupo
    • Moneda de las facturas
  4. Cerrar Modal: Hacer clic en "Cerrar" o presionar Escape

💳 Procesar Pagos

Guía Completa de Procesamiento

Paso 1: Iniciar Proceso
  1. En la tabla de pagos pendientes, hacer clic en el botón "Pagar" (ícono de tarjeta)
  2. Se abrirá el modal de procesamiento de pago
  3. Las facturas estarán seleccionadas por defecto
Paso 2: Configurar Pago
  • Moneda de Pago: Seleccionar entre VES, USD o COP
  • Monto a Pagar: Ingresar el monto (puede ser parcial)
  • Fecha de Pago: Seleccionar la fecha del pago
  • Comprobante: Subir imagen del comprobante (opcional)
  • Notas: Agregar observaciones (opcional)
Paso 3: Verificar Conversión
  • El sistema mostrará automáticamente la conversión a USD
  • Se indicará si es pago parcial o completo
  • Se mostrará la tasa de cambio utilizada
Paso 4: Confirmar Pago
  1. Revisar todos los datos ingresados
  2. Hacer clic en "Procesar Pago"
  3. Esperar confirmación de éxito
  4. El modal se cerrará automáticamente

💰 Tipos de Pago

Pago Completo vs Parcial

Pago Completo
  • Condición: Monto pagado ≥ Total de facturas
  • Estado: Facturas marcadas como "paid"
  • Indicador: Sin alertas especiales
Pago Parcial
  • Condición: Monto pagado < Total de facturas
  • Estado: Facturas marcadas como "partial"
  • Indicador: Alerta amarilla con monto restante

🔄 Conversión de Monedas

Sistema de Conversión Automática

  • Monedas Soportadas: VES (Bolívares), USD (Dólares), COP (Pesos)
  • Conversión: Todos los pagos se convierten automáticamente a USD
  • Tasas: Utiliza las tasas de cambio más recientes del sistema
  • Visualización: Muestra monto original y equivalente en USD
  • Precisión: Cálculos redondeados a 2 decimales

📁 Gestión de Comprobantes

Subida de Archivos

  • Formatos Soportados: JPG, PNG, GIF
  • Tamaño Máximo: 2MB
  • Proceso: Seleccionar archivo en el modal de pago
  • Almacenamiento: Se guarda automáticamente en el servidor
  • Asociación: Se vincula automáticamente con el pago

📈 Estados de Pago

Estados del Sistema

  • Pendiente: Factura sin pagar (estado inicial)
  • Parcial: Pago parcial realizado
  • Pagado: Pago completo realizado
  • Vencido: Factura con fecha de pago pasada

🔧 Funcionalidades Automáticas

Procesos Automáticos al Pagar

  • Actualización del estado de las facturas
  • Creación de registro en la tabla de pagos
  • Generación de gasto en el módulo de expenses
  • Creación de la categoría "Pagos de Facturas" si no existe
  • Establecimiento de relaciones entre facturas y pagos
  • Actualización de las estadísticas del dashboard

📖 Manual de Usuario - Historial de Pagos

🔍 Acceso al Historial

Navegación al Historial

  1. Desde el Módulo "Por Pagar": Hacer clic en "Ver Historial" en el dashboard
  2. Desde el Sidebar: Expandir "Finanzas" y seleccionar "Historial de Pagos"
  3. URL Directa: Navegar a /finances/payment-history

📊 Vista del Historial

Elementos de la Interfaz

  • Filtros Avanzados: Búsqueda por factura, proveedor, moneda y fechas
  • Tabla de Pagos: Lista de todos los pagos realizados
  • Paginación: Navegación por páginas de resultados
  • Acciones: Ver detalles y comprobantes

🔍 Filtros del Historial

Opciones de Filtrado

  • Búsqueda por Factura: Campo de texto para buscar por número de factura
  • Proveedor: Lista desplegable con todos los proveedores
  • Moneda: Filtro por VES, USD o COP
  • Fecha Desde: Fecha de inicio del rango
  • Fecha Hasta: Fecha final del rango
  • Limpiar Filtros: Resetear todos los filtros

📋 Información de la Tabla

Columnas Disponibles

  • Fecha de Pago: Fecha en que se procesó el pago
  • Proveedor: Nombre del proveedor con avatar
  • Facturas: Números de factura pagadas (chips clicables)
  • Monto: Cantidad pagada en la moneda original
  • Moneda: Código de moneda con color distintivo
  • Equivalente USD: Monto convertido a dólares
  • Comprobante: Botón para ver comprobante si existe
  • Usuario: Usuario que procesó el pago
  • Acciones: Ver detalles del pago

👁️ Ver Detalles de Pago

Modal de Detalles

  1. Hacer Clic en "Ver": Presionar el botón de acciones
  2. Información Mostrada:
    • Fecha de pago
    • Monto pagado en moneda original
    • Equivalente en USD
    • Usuario que procesó el pago
    • Lista detallada de facturas pagadas
    • Información del proveedor
  3. Cerrar Modal: Hacer clic en "Cerrar" o presionar Escape

📄 Ver Comprobantes

Visualización de Archivos

  1. Localizar Pago: Encontrar el pago con comprobante
  2. Hacer Clic en "Ver": Presionar el botón de comprobante
  3. Modal de Imagen: Se abrirá mostrando la imagen
  4. Navegación: Usar controles para ampliar/reducir
  5. Cerrar: Hacer clic fuera de la imagen o presionar Escape

🎨 Códigos de Moneda

Colores y Códigos Estandarizados

  • VES (Bolívares): Código naranja - Todos los códigos BS/Bs se muestran como VES
  • USD (Dólares): Código verde - Dólares americanos
  • COP (Pesos): Código azul - Pesos colombianos

Nota: El sistema normaliza automáticamente todos los códigos de moneda para consistencia visual.

📊 Exportación y Reportes

Funcionalidades de Exportación

  • Filtros Aplicados: Los reportes respetan los filtros activos
  • Formato: Exportación en formato estándar del sistema
  • Datos Incluidos: Todos los campos visibles en la tabla
  • Rango de Fechas: Basado en los filtros de fecha seleccionados

⚠️ Consideraciones Importantes

Notas de Uso

  • Datos Históricos: El historial muestra todos los pagos procesados
  • Filtros Persistentes: Los filtros se mantienen durante la sesión
  • Rendimiento: Para grandes volúmenes, usar filtros de fecha
  • Acceso: Requiere permisos de visualización de pagos
  • Integridad: Los datos mostrados son de solo lectura
