🔄 Flujo de Datos

  1. Frontend (Vue.js): Componente Vue hace llamada HTTP
  2. Rutas (Laravel): routes/api.php define endpoints
  3. Controlador: app/Http/Controllers/Api/ procesa la petición
  4. Modelo: app/Models/ interactúa con la base de datos
  5. Respuesta: JSON devuelto al frontend

⚠️ 2. CONSIDERACIONES CRÍTICAS

🚨 Problemas Comunes y Soluciones

PROBLEMA 1: Proxy de Vite no redirige correctamente

Síntomas: API devuelve HTML (página de login) en lugar de JSON

Causa: El proxy de Vite no está configurado correctamente para ciertas rutas

Solución: Usar URLs absolutas en lugar de relativas en el frontend

// ❌ INCORRECTO (puede fallar con proxy) const response = await axios.get('/api/mi-modulo/datos'); // ✅ CORRECTO (llamada directa al servidor) const response = await axios.get('http://127.0.0.1:8000/api/mi-modulo/datos');
PROBLEMA 2: Autenticación con Laravel Sanctum

Síntomas: Errores 401/419 en llamadas autenticadas

Causa: Configuración incorrecta de Sanctum o cookies de sesión

Solución: Verificar configuración de Sanctum y CORS

// Configuración correcta en config/sanctum.php 'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS', sprintf( '%s%s', 'localhost,localhost:3000,127.0.0.1,127.0.0.1:8000,::1', env('APP_URL') ? ','.parse_url(env('APP_URL'), PHP_URL_HOST) : '' ))), // Configuración correcta en config/cors.php 'allowed_origins' => [ 'http://localhost:3000', 'http://127.0.0.1:3000', 'http://[::1]:5173', 'http://127.0.0.1:5173', ],
PROBLEMA 3: Conversión de monedas

Síntomas: Cálculos incorrectos en módulos financieros

Causa: No usar campos USD para cálculos unificados

Solución: Siempre usar campos con sufijo _usd para cálculos

// ❌ INCORRECTO (mezcla monedas) $total = Order::sum('total_amount'); // ✅ CORRECTO (solo USD) $total = Order::sum(DB::raw('COALESCE(total_amount_usd, total_amount)'));

🛣️ 4. CONFIGURACIÓN DE RUTAS

📝 Patrón de Rutas API

// En routes/api.php // Rutas de autenticación (siempre al inicio) Route::post("/login", [LoginController::class, "login"]); Route::post("/two-factor-challenge", [LoginController::class, "verify2FA"]); // Rutas públicas (no requieren autenticación) Route::get("/public/exchange-rates", [ResourceController::class, "getExchangeRates"]); // Rutas protegidas que requieren autenticación Route::middleware("auth:sanctum")->group(function () { Route::get("/user", function (Request $request) { return $request->user(); }); Route::post("/logout", [LoginController::class, "logout"]); // Agrupar rutas por módulo Route::prefix("finances")->group(function () { Route::get("/income-statement", [FinancialStatementController::class, "index"]); Route::get("/income-statement/summary", [FinancialStatementController::class, "getSummary"]); Route::get("/income-statement/details", [FinancialStatementController::class, "getDetails"]); // ... otras rutas de finanzas }); Route::prefix("products")->group(function () { Route::get("/", [ProductController::class, "index"]); Route::post("/", [ProductController::class, "store"]); // ... otras rutas de productos }); });

⚠️ Consideraciones Importantes

  • Rutas públicas: Solo para datos que no requieren autenticación
  • Rutas protegidas: Usar middleware auth:sanctum
  • Agrupación: Agrupar por módulo usando prefix()
  • Nombres descriptivos: Usar nombres claros y consistentes

🔧 9. TROUBLESHOOTING

🚨 Problemas Comunes

Error: "Cannot read properties of undefined"

Causa: Datos no cargados correctamente desde la API

Solución: Verificar que la API devuelve datos y usar valores por defecto

// Usar valores por defecto const data = ref([]); const summary = ref({}); // Verificar antes de acceder if (summary.value.income) { // Acceder a la propiedad }
Error: "Network Error" o "ERR_CONNECTION_RESET"

Causa: Servidor Laravel no está corriendo o proxy de Vite falla

Solución: Verificar que Laravel esté corriendo y usar URLs absolutas

Error: "401 Unauthorized"

Causa: Problema de autenticación con Sanctum

Solución: Verificar configuración de Sanctum y CORS

Error: "500 Internal Server Error"

Causa: Error en el backend (consulta SQL, lógica de negocio)

Solución: Revisar logs de Laravel y validar consultas SQL
