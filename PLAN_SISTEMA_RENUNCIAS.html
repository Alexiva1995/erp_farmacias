📋 Plan de Implementación - Sistema de Renuncias

Proyecto: ERP Farmacias - Módulo RRHH

Fecha:

Desarrollador: Asistente AI

🎯 Objetivo

Implementar un sistema para generar cartas de renuncia de empleados con notificación automática a Jesús Freita para el proceso de liquidación, sin modificar la base de datos existente.

📊 Análisis de la Situación Actual

✅ Funcionalidades Existentes

  • Gestión de Empleados: CRUD completo implementado
  • Sistema de Roles: Admin, Supervisor, Employee
  • Despido Básico: Método fire() que cambia is_active = false
  • Generación de PDFs: Sistema existente para documentos
  • Notificaciones: Patrones implementados para servicios externos

❌ Limitaciones Identificadas

  • No existe tabla de renuncias en la base de datos
  • No hay registro de fechas de renuncia o tipos
  • No hay integración con sistema de liquidación
  • No hay generación de cartas formales

⚠️ Restricciones del Proyecto

  • NO se puede modificar la base de datos
  • NO se pueden crear nuevas tablas
  • NO se pueden agregar nuevos campos
  • Solo se permite consultar datos existentes

🏗️ Arquitectura de la Solución

Estrategia: Generación Local + Notificación Externa

Enfoque: Generar PDFs localmente y enviar datos a Jesús Freita para almacenamiento y procesamiento de liquidación.

Flujo de Trabajo

1. Admin selecciona empleado

Desde el listado de empleados, hace clic en "Generar Renuncia"

2. Captura de datos

Modal para seleccionar tipo de renuncia y fecha efectiva

3. Generación de PDF

Crear carta de renuncia usando template proporcionado

4. Notificación a Jesús Freita

Enviar datos vía API/webhook para procesamiento de liquidación

5. Actualización de empleado

Cambiar estado a inactivo usando método fire() existente
